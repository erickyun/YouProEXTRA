# HideChannelMembers .deb
Experimental YouTube iOS tweak that attempts to hide the "Üyelerimiz / Our Members" recognition shelf from channel Home pages without hiding videos.
Build: GitHub Actions -> Build Hide Channel Members Deb. Download the artifact ZIP, extract the .deb, then use the YouProEXTRA custom .deb IPA workflow.
This package has not been tested on a real YouTube version or iPhone. It will not affect memberships or visibility for other YouTube users.
