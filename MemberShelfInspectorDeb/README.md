# MemberShelfInspector 0.1.0
Diagnostic only; **does not hide** the members shelf. Inject into a clean decrypted YouTube IPA using YouProEXTRA minimal workflow (custom-only). Do not inject alongside HideChannelMembers.
Open YouTube, navigate to @gamerig -> Home, ensure **Our Members** is on screen, tap **Inspect** at the top right, paste the copied report into ChatGPT.
The report contains matched view hierarchy class names and recognition shelf markers. It does not record video titles, channel names, or account data and does not transmit it over the network.
This is an experimental, not-yet-tested iOS diagnostic.
